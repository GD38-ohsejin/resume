포트폴리오 열람 로그

아직 불러오지 않았어요

지금 보이는 건 예시 데이터예요. 아래 연결 설정을 마치면 실제 기록으로 바뀌어요.

연결 설정

처음 설정하는 방법
  1. 구글 드라이브에서 새 구글 시트를 만들고, 메뉴의 확장 프로그램 → Apps Script를 엽니다.
  2. apps-script/Code.gs 내용을 통째로 붙여넣고, 맨 위 DASHBOARD_KEY 값을 나만 아는 문구로 바꾼 뒤 저장합니다.
  3. 배포 → 새 배포 → 유형 웹 앱, 다음 사용자로 실행 나, 액세스 권한 모든 사용자로 배포합니다. 처음엔 구글 권한 확인 창이 뜨는데 허용하면 됩니다.
  4. 나온 웹 앱 URL을 config.js 의 window.PF_LOG_URL = ''; 따옴표 안에 넣습니다. 홈페이지와 입사지원서가 함께 이 주소를 씁니다.
  5. index.html, resume.html, config.js, log.html 을 GitHub 저장소에 올리고 Settings → Pages에서 배포합니다.
  6. 배포된 …/log.html을 열어 위 칸에 웹 앱 주소와 비밀번호를 넣고 저장합니다. 내 열람이 섞이지 않게 내가 보는 건 기록하지 않기도 켜 두세요.
  7. 아래 회사별 링크 만들기에서 지원하는 회사마다 링크를 만들어 보내면, 그 링크로 들어온 열람이 회사별로 정리돼요.
